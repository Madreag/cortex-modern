Corefall Ideas

Design ideas mined from Corefall — the sister project — and what each would cost to bring into Cortex Command. Every idea is split into what ships as a Lua/INI mod versus what needs an engine code change. Built from a full read of Corefall's milestone specs and cross-checked against the live Cortex Command engine source.

Clean-room boundary — ideas only, one direction

Corefall is licensed Apache-2.0 / MIT and is a deliberate clean-room design — it copies no code or assets from any inspiration game. Cortex Command / cortex-modern is AGPL-3.0. Design ideas may inform either project, and Corefall-inspired features may be implemented fresh in cortex-modern. But no Cortex Command code or assets may ever go into Corefall — that would breach the licence and destroy its clean-room status. This page is strictly Corefall → cortex-modern.

The headline — physics is theirs, design is portable

Corefall is a from-scratch deep-simulation game (~170 milestone specs). Mined for Cortex Command, its ideas split sharply along one line:

Its physics is [ARCH] and is Corefall's whole identity. PV=nRT atmospherics, Noita-grade material cellular-automata, per-tile thermal, fluid and vehicle dynamics — these are new simulation cores. You cannot mod them into Cortex Command, and rebuilding them just reproduces Corefall in a weaker engine. Leave deep sim to Corefall.

Its design is overwhelmingly [MOD] for Cortex Command. Causal damage, afflictions, AI & squad command, loot, factions, missions, storytellers, traits, progression, morale, memory — these map onto Cortex Command's existing modding surface (Lua scripts, GAScripted, GlobalScript, the PieMenu, AEmitter wounds, the buy menu) so cleanly that most of it could ship as ordinary .rte mods with no engine fork at all. The classifications below were checked against the actual engine source — see Technical Analysis.

Already in Cortex Command

Corefall openly takes its core fantasy from Cortex Command and reimplements it clean-room, so several “Corefall systems” are things Cortex Command already has — nothing to port: brain-hopping, limb-driven walking (Corefall's LimbPath loop is a port of CC's AHuman walk cycle), per-pixel atom collision and terrain penetration (impulse² > integrity²), gibbing and joint-impulse limb detachment, ragdoll-on-death, the buy menu + delivery craft, the painted intro slideshow, an adaptive-music engine (MusicMan), and live script hot-reload (ReloadScripts).

The verdict — what to actually pursue

Don't turn cortex-modern into Corefall. The [ARCH] pillars — atmospherics, material cellular-automata, thermal fields, vehicle and fluid physics, a replay/determinism core, a multiplayer rework — are multi-year efforts that duplicate Corefall's reason to exist. Track them as inspiration, not as work.

Harvest the [MOD] tier. It is large, cheap, and fits Cortex Command's identity: deeper AI & squad command (also closes upstream issue #208), causal damage + afflictions, a mission-director / storyteller layer, factions & diplomacy, roguelike loot / perks / weapon modifiers, and the whole traits / morale / memory colony layer. Critically, every [MOD] idea here can be prototyped as a plain Cortex Command .rte mod today — no fork, no recompile — which makes this a low-risk content track that runs in parallel with the engine Roadmap.

The one enabling [CODE] investment that multiplies everything: widen the Lua API and add a custom-property mechanism. A handful of ideas below are “[MOD] given one missing setter or one event hook” — each such binding is a near-trivial change that converts a whole cluster of ideas into pure mod work. See ADR-010 for the standing posture.
