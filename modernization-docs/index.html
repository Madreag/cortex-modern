Cortex‑Modern Modernization Effort

A working wiki, plan and decision tracker for modernizing our fork of the Cortex Command Community Project.

The headline finding

This is not a 2007 codebase. The development branch we forked is an unreleased v7.0 carrying ~2 years of un-shipped modernization: SDL3, a new OpenGL/raylib GPU renderer, multithreaded Lua scripting, a new adaptive-music engine, a pathfinding overhaul, compressed saves, and the removal of the old multiplayer.

So the real task is not "modernize an old game" — it is "finish a modernization that is already ~70% done." The remaining 30% is a small set of deeply-rooted architectural cores, mapped precisely in the Technical Analysis.

Active plan — what's happening now

2026-06-05 — the determinism foundation is DONE and cross-platform GREEN

The hard part of Stage 1 is finished and proven. The simulation now replays bit-for-bit identically — a multi-core run is byte-identical to a single-core run — on Windows, Linux, and macOS. That bit-identical multi-core==single-core result across all three platforms was the entire challenge of the determinism foundation.

It is repackaged into a single numeric sequence of 10 small, reviewable per-concern PRs (no "PR A/B/C/D" letters, no "Wave 1/2/3"):

  • PR 1 — LuaJIT WohlSoft vendor bump: MERGED upstream #279
  • PR 2 — LuaJIT Windows source build: MERGED upstream #280
  • PR 3 — vendor nlohmann/json (test-report format only); PR 4 cross-platform stability + FP contract; PR 5 LuaJIT STRID=0; PR 6 M2 Lua determinism; PR 7 M0/M1 foundation (SimChecksum + RNG split); PR 8 Path E threaded-sim determinism; PR 9 cccp-ctl harness + scenarios — all BUILT + VERIFIED (clean per-concern branches, determinism-GREEN in the integrated build).
  • PR 10 — CI determinism gates: IN PROGRESS (being built by a dispatched agent, 2026-06-05).

Nothing is shipped upstream yet beyond the two merged LuaJIT PRs — 0 of PRs 3–10. What remains to close Stage 1: PR 10 finishes → build+boot every cumulative PR state on Windows (the "never ship a broken PR" gate) → feed PRs 3–10 to Causeless one at a time. Then Stage 2 — the multiplayer itself — begins.

Technical decisions since 2026-05-25 (the r7 finalization): the global det_pairs() replacement was dropped → stock pairs() + LUAJIT_SECURITY_STRID=0 (string-key iteration is deterministic because STRID=0 makes string-ids allocation-ordered); the BLAKE3 crypto vendor was dropped → a built-in FNV-1a/splitmix64 hash in SimChecksum; nlohmann/json is kept (test-report only); M3 Q40.24 fixed-point is rejected → FPU + libm standardization is the cross-platform path. The canonical PR plan is D:/Projects/PRs/PR_ROADMAP.html. See ADR-018 + ADR-019 in the Decision Log.

How to use this wiki

This is git-tracked plain HTML — no build step, no server. The git history of modernization-docs/ is the change history of the plan.

  • Add a work item → edit the WORK_ITEMS array in tracker.html, commit.
  • Record a decision → add an ADR card to decisions.html, commit.
  • Update findings → edit analysis.html / roadmap.html, commit.

Keep edits small and commit often.
