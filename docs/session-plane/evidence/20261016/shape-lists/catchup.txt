The image path has five real gaps: (1) the NEW catch-up pacing (212c775be/923507b13/cd52678d3 on the harness branch, not on relay-findings) can stop converging: with the 2-tick floor a returner whose 2 ticks plus one draw take 33.3 ms or more replays at 60 ticks/s or slower and never closes - round trip plays no part; the current 16-ticks-a-frame rule converges in that case; (2) the image path has no 'can it close its trail' gate (the in-place return got it in 6f6470048): a returner at the edge of its capacity is let back while trailing and in 3+ seats the others stall on its late inputs for up to ~2 s before it is held again; (3) a stale image error blocks later returners (one refused reclaim sets a host-wide error that blocks every later image transfer, cleared only by a fresh capture); (4) every cancelled return counts as a failure (benign cancels - held again, a capture park, a lag rebase - count toward the 3-failure cap that ends image returns until relaunch); (5) while the host's own seat is held no base for another returner can be named (refused after 40 s).
